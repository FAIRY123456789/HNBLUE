# HNBLUE 系统背景与设计说明

## 系统背景
在碳达峰与碳中和目标下，蓝碳生态系统被视为最重要的自然碳库之一，对碳汇测算与生态管理具有关键意义。由于蓝碳数据多源异构、估算模型难以解释、人工问答门槛高，亟需借助人工智能与软件工程方法，构建高效、透明、可交互的数字化平台。

## 设计目标
HNBLUE 系统旨在为海南蓝碳生态监测与管理提供一体化的数字化支持。系统目标包括：  
（1）构建高精度碳储建模模块，实现面向全国与区域的碳储预测与解释；  
（2）集成智能问答助手，支持生态知识的快速获取与结构化解释；  
（3）搭建统一的前后端架构，支持数据管理、可视化分析与交互展示；  
（4）通过功能测试与模糊测试验证系统稳定性与鲁棒性，保证核心功能可用。

## 系统实现
系统采用 Vue.js + Spring Boot 技术栈，前端实现交互式地图与指标可视化，后端对接 MySQL 与 Redis Cluster，负责用户与指标管理。独立的 Flask 服务封装 CatBoost 模型，提供碳储预测与敏感性分析接口。智能助手由 AnythingLLM 桌面端与 DeepSeek API 共同支撑，实现私域知识问答功能。  

经功能测试与接口级模糊测试验证，系统主要功能运行稳定，能够在面对正常与异常输入时保持可靠性。
