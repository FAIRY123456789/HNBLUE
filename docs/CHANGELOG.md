# HNBLUE 系统更新日志（CHANGELOG）

## v3.0.0-public （2026-10-06）

- 以 HNBLUE 自建混合检索与 Spring Agent 编排替换旧知识助手链路；
- 增加证据充分性、提示注入、冲突识别、引用合法性和摘录式降级策略；
- 增加按用户/匿名会话隔离的历史与最小化记忆；
- 新增公开合成 RAG 知识包、合成检索评测题和 Python/Spring 测试；
- 移除 Git 中的私有知识、真实/授权数据快照、训练模型、运行日志、压测明细和交付证据；
- 模型服务默认进入 `synthetic-demo`，私有模型改为运行时挂载；
- 重写中英文 README、架构、API、产品需求与公开数据策略。

## v1.0.0 （2025-08-25）
- 初始版本发布  
- 后端（Spring Boot + MySQL + Redis Cluster）实现用户认证、区域与指标接口  
- 模型服务（Flask）提供碳储预测与敏感性分析接口  
- 前端（Vue.js + ECharts）实现区域地图、趋势分析与专题功能
- 集成当时的第三方知识工作区与生成 API（已在 v3.0.0-public 完全移除）
- 功能测试与接口级模糊测试通过，系统核心功能稳定
