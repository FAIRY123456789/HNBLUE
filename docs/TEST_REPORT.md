# HNBLUE 测试报告（TEST_REPORT）

## 1. 测试目标与范围
为保证海南蓝碳数字化应用系统主要功能可用，本阶段对系统主要功能进行功能测试和接口级模糊测试，以检验系统在正常输入与异常输入下的稳定性和鲁棒性。

---

## 3. 模糊测试

模糊测试用于评估系统在异常输入下的鲁棒性，确保服务在面对非法或边界输入时能正确返回错误，而不会崩溃或泄漏内部信息。测试采用 MockMvc 结合 FuzzUtil 工具，通过自动化脚本对核心接口执行随机化非法输入模拟。

### 模糊测试用例（表 3）

| 编号 | 功能描述              | 主要行为                         | 基本输入                              | 测试结果   |
|------|-----------------------|----------------------------------|---------------------------------------|------------|
| TC1  | 登录接口模糊测试      | 使用非法用户名和 SQL 注入密码登录 | 随机非法用户名，SQL 注入型密码        | 4xx 错误  |
| TC2  | 注册接口模糊测试      | 使用非法字符、超长输入注册        | 随机非法用户名、密码、邮箱、出生日期  | 4xx 错误  |
| TC3  | 指标更新接口模糊测试  | 使用非法区域名和指标名更新        | 随机区域名，随机指标名，非法浮点数    | 4xx 错误  |
| TC4  | 区域详情接口模糊测试  | 通过超长字符串作为区域名查询      | 超长区域名（1000 字符）               | 4xx 错误  |
| TC5  | 非法字符输入模糊测试  | 特殊符号输入                      | 特殊符号                              | 4xx 错误  |

模糊测试结果表明，在所有异常输入场景下，系统均返回 4xx 客户端错误码，无服务崩溃现象，接口响应一致且具备可读性。这验证了系统在输入边界与非法输入情况下的鲁棒性和基础安全性。
