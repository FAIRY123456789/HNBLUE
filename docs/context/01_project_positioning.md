# HNBLUE 项目定位与建设边界

HNBLUE 的当前定位是“海南蓝碳数字化应用系统”。它服务于海南省典型蓝碳生态系统，当前主要围绕红树林生态系统展开，重点承接蓝碳生态碳汇数据库、碳储量估算、碳通量与碳储量数据管理、模型解释、专题可视化和智能问答等任务。

项目的上位背景来自海南省重点研发项目“蓝碳生态碳汇数据库与数字化应用平台”。该课题强调红树林和海草床是 IPCC 承认的滨海蓝碳生态系统，海南需要建设蓝碳碳汇机制和标准体系。实施方案中提出，要构建陆海梯度蓝碳碳汇联网长时序立体观测体系，融合地面观测和无人机低空遥感技术，建立海南典型蓝碳生态系统碳汇数据库，并研发蓝碳评估分析与数字化应用平台。

HNBLUE 在现阶段应采取“可实现优先”的工程定位。项目可以吸收 WebGIS、ArcGIS 空间分析和省域蓝碳数据库等上位方案的总体方向，但当前版本不强制实现完整 WebGIS。现阶段更现实的目标是构建一个可部署、可演示、可查询、可上传、可解释、可持续扩展的蓝碳数据与模型应用平台。

HNBLUE V2.0 的核心价值应聚焦于三点。第一，形成统一的数据目录、字段字典、版本记录和质量标识，使碳储量、碳通量、遥感产品、无人机影像、样方调查和文献资料能够被清晰管理。第二，把 CatBoost 碳储估算模型、SHAP 解释、敏感性分析和情景模拟组织成可复用的科研分析模块。第三，将 AI 碳助手作为平台的解释层，用于说明指标含义、模型原理、数据口径和结果不确定性。

平台面向的主要用户包括管理部门、科研团队、保护区管理机构、项目协同单位以及后续公众科普用户。V2.0 的重点用户应优先设定为管理端和科研端。管理端关注数据是否可追溯、材料是否可复用、结果是否能支撑阶段汇报。科研端关注数据来源、模型方法、变量解释和图件输出。
