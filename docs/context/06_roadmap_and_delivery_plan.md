# 建设路线与交付计划

V2.0 建设应遵循“先可运行，再可扩展，再可验收”的顺序。当前阶段的核心目标是降低本地启动成本，整理数据结构，形成文昌示范区演示，完成可部署版本，并为后续真实数据接入预留稳定接口。

Phase I 为文昌示范区基础数据交付与可用化。该阶段需要完成数据目录、字段字典、文昌示范数据、通量塔数据结构、遥感产品元数据结构、样方数据结构、导入脚本和基础页面。平台侧交付包括数据库初始化脚本、示范数据导入、文昌专题页面、数据来源标识和基础可视化。

Phase II 为通量与遥感产品的稳定更新机制。该阶段需要形成 CSV 或 Excel 批量导入、文件挂载、版本更新、质量标识维护和半自动更新流程。平台侧交付包括数据上传入口、数据校验、更新日志、版本管理和图表自动刷新机制。

Phase III 为从文昌扩展到省域节点。该阶段需要把文昌数据模型推广到更多市县、保护区和监测站点。平台侧交付包括多节点区域管理、省域专题图件、跨区域指标对比、区域报告模板和可复用科普内容模块。

两周开发窗口内建议采用压缩目标。第一优先级是统一启动与部署，包括前端、后端、模型服务和数据库脚本的最小运行说明。第二优先级是文昌示范数据和页面，包括数据库表、导入脚本、文昌专题图表和数据说明。第三优先级是 AI 碳助手知识材料整理，包括模型解释、数据口径、文昌示范问答和不确定性说明。第四优先级是遥感和无人机文件元数据管理，先实现元数据登记和列表检索，再考虑地图叠加。

阶段验收材料建议包括：系统运行截图、数据目录截图、文昌专题页面截图、碳储估算页面截图、AI 碳助手问答截图、数据库 ER 图或表结构说明、部署说明、接口说明、示范数据说明和后续接入路线。
