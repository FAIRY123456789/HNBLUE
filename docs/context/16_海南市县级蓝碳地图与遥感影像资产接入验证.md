- 市县级 GeoJSON：19 个 feature，regionCode 全部为字符串。

- 关联优先级：regionCode 精确匹配、正式全称匹配、已确认 alias 匹配；站点、港湾和保护地记录保持 unmatched，不强制映射为市县。

## 6. 使用边界

- 遥感制图产品用于展示论文研究方法和空间分布特征，不代表平台实时监测结果。
- 科研图件不能直接用于正式碳核算或行政审批结论。
- CC BY 复用需保留作者、论文、期刊、Figure、DOI、来源链接和许可说明。
- 市县级红树林面积、碳储量和碳汇量只有在取得已核验来源时展示；本轮未进行推算。
