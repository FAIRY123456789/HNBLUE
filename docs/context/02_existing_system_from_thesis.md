# HNBLUE V1.0 已有系统能力

本科毕业论文《海南蓝碳数字化应用系统设计与实现》已经完成了 HNBLUE V1.0 的主要设计与实现。该版本采用 Vue.js、Spring Boot、MySQL、Redis、Flask、CatBoost、AnythingLLM 和 DeepSeek API 共同构成系统基础。

现有系统的第一项核心能力是 CatBoost 碳储估算。论文中基于 BAAD 森林样本数据构建碳储估算模型，使用结构变量、环境变量和分类变量作为输入，采用 RMSE、MAE 和 R² 评价模型性能。论文记录的结果为：全国尺度测试中 CatBoost 模型 R² 为 0.947，RMSE 为 0.649，MAE 为 0.265；类红树林样本测试中 R² 为 0.980，RMSE 为 0.426，MAE 为 0.158。模型解释方面使用 SHAP 分析变量贡献，重点解释树高、冠幅、胸径、经纬度、降水和温度等变量对估算结果的影响。

现有系统的第二项核心能力是 AI 碳助手。论文中设计了基于 AnythingLLM 私域知识库和 DeepSeek API 的蓝碳私域大模型。私域知识目录包含模型说明、结构变量解释、图像输出说明、虚拟样地实验、碳估价、常见问答和元信息管理。AI 碳助手主要用于解释模型原理、结构变量生态意义、SHAP 图件、参数扰动结果和蓝碳应用场景。

现有系统的第三项核心能力是可视化分析。V1.0 采用 Vue.js 与 ECharts 构建省级视图和市县详情页。省级视图基于海南省地图展示区域蓝碳指标。市县详情页包含碳储量与碳通量趋势、通量类型对比、多碳指标对比、通量影响因子分析、多年趋势、优势物种分布和蓝碳经济价值估算等模块。

现有系统的第四项能力是基础工程框架。后端采用 Spring Boot 承载用户管理、业务接口和数据服务。MySQL 存储结构化蓝碳数据、用户数据和模型结果。Redis 用于验证码、会话、访问令牌和高频状态数据。Flask 独立部署 CatBoost 模型服务，并向前端返回估算结果与解释输出。

V2.0 开发应尽量复用上述基础。重点工作应放在降低启动复杂度、统一运行入口、整理数据库脚本、补充文昌示范区数据接入、完善文件型遥感数据元数据管理、整理 AI 碳助手知识材料和完成可部署版本。
