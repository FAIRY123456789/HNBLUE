# HNBLUE V2.0 文昌示范区需求

V2.0 应以文昌示范区作为优先落地对象。文昌在当前阶段承担“对象模型与技术口径先行固化”的作用。平台需要先把区域对象、指标体系、数据表结构、接口契约、模型服务和解释口径固定下来，再扩展到海南省更多市县和保护区节点。

文昌示范区的数据接入应优先覆盖三类对象。第一类是通量塔数据，包括连续时间序列、站点元数据、质量标识、缺测标识和异常标识。第二类是遥感与无人机数据，主要形态为 GeoTIFF、正射影像、冠层高度模型、数字表面模型、地上碳储量栅格和相关产品说明。第三类是样方调查和文献资料，包括样方位置、调查记录、树种、结构参数、碳储量或生物量结果、文献来源和版本信息。

当前系统不能假设所有真实数据已经交付。V2.0 应允许使用公开数据、历史示范数据和必要模拟数据完成演示，同时为后续真实数据接入预留字段和接口。平台需在页面和文档中清楚区分真实观测数据、公开数据、模拟数据和待接入数据。

管理端展示应突出工程准备度。页面可展示通量塔表结构、遥感产品元数据、字段字典、质量标识、版本追溯、数据共享范围和专题数据包。该方向服务于阶段汇报和项目验收。

科研端展示应突出模型能力。页面可展示结构变量输入、CatBoost 推理结果、SHAP 解释、敏感性分析、响应曲线、虚拟样地情景模拟、文献参考区间和碳价值换算。该方向服务于论文、组会和专家沟通。

公众或研学端展示应突出知识表达。页面可围绕文昌红树林树种、群落结构、生态功能、碳储量和碳通量关系组织可读材料，并通过 AI 碳助手提供分层解释。

V2.0 的最小可交付版本应包含以下能力：统一启动说明、数据库初始化脚本、文昌示范数据、数据目录页面、文昌专题页面、碳储估算页面、AI 碳助手入口、若干稳定图表、系统说明文档和部署说明。
