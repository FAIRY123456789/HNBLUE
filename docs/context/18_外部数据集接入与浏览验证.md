## 4. API 设计

- `GET /api/v2/external-datasets`：返回四个数据集概览。
- `GET /api/v2/external-datasets/{datasetId}/tables`：返回真实表清单、记录数、字段数和数据源类型。
- `GET /api/v2/external-datasets/{datasetId}/schema?tableName=&page=&size=&keyword=`：返回字段字典。
- `GET /api/v2/external-datasets/{datasetId}/records?tableName=&page=&size=&keyword=&sortField=&sortDirection=`：返回真实记录分页。

记录响应包含 `datasetId`、`tableName`、`page`、`size`、`totalElements`、`totalPages`、`columns`、`records` 和 `source`。

## 5. 分页、搜索和排序

- 默认每页 20 条，可切换 20、50、100 条。
- 支持第一页、上一页、下一页、最后一页和页码输入跳转。
- 翻页保持当前数据表、关键词和排序条件。
- CSV 由后端流式解析；浏览器不会一次加载大型文件。
- MySQL 表名只允许来自预设候选白名单；字段名必须来自当前真实表结构。
- CSV 排序字段必须来自当前真实表头；非法字段返回 HTTP 400。
- 关键词作为 JDBC 参数传递，不拼接为不受控 SQL。
- 数据库行会过滤密码、Salt、Token、Secret、API Key 等敏感字段名。

## 6. 字段字典

字段字典统一输出：

`columnName`、`displayNameCn`、`dataType`、`unit`、`description`、`category`、`displayPriority`、`nullable`、`sourceTable`。

关键字段包括：

- BAAD：研究、地点、经纬度、温度、降水、物种、科、功能型、尺寸、器官生物量、地上与总生物量等。
- Tallo：`tree_id`、分类、经纬度、`stem_diameter_cm`、`height_m`、`crown_radius_m`、离群标识和 `reference_id`。
- ChinAllomeTree：样本地理与林分背景、树种/组分、预测变量、方程形式、系数、样本量、R²、适用直径和树高范围。
- GWM：国家代码、生态系统总面积、保护覆盖面积和保护覆盖比例。

完整字段列表来自真实表头或 `information_schema.columns`，不会隐藏真实表名和字段名。

卡片 hover 使用约 1.025 倍缩放、边框高亮、阴影增强和 240 ms 过渡，不改变网格占位。详情层支持 Esc 关闭、焦点定位、语义化 dialog 和深浅主题。

## 8. Redis 缓存评估

本轮未为外部数据集新增 Redis 缓存。数据集概览、表清单和字段字典适合后续使用 `hnblue:cache:v2:external-datasets:` 前缀缓存；真实记录分页涉及关键词、表、页码、页大小和排序条件，当前保持不缓存。CSV 文件结构与记录总数使用后端进程内只读 profile 缓存，源文件重启后重新计算。

### 浏览器验收

本轮已在 `http://127.0.0.1:8084` 启动前端，并以 `http://127.0.0.1:8094` 的隔离后端完成接口联调。浏览器控制连接连续三次被当前 Windows 沙箱的 `helper_unknown_error` 中断，因此未完成标签页中的目视与交互验收。已完成的替代检查包括生产构建、四卡片/弹窗/表格组件源码审查、favicon 文件格式与尺寸检查、HTML/manifest 引用检查及 Vue 图标引用全量扫描；这些检查不能替代浏览器标签页验收。

## 10. 已知限制

- 浏览器标签页验收尚未完成；需在浏览器控制环境恢复后复核 favicon 实际显示、四张卡片、Hover、四个详情弹窗、主题切换、窄屏布局和控制台错误。
- 当前终端缺少数据库运行凭据，候选 MySQL 外部明细表的行数、字段、主键、索引和随机 20 行一致性尚未取得；前端因此使用本地 CSV。
- CSV 关键词查询需要顺序扫描当前文件；Tallo 全字段查询的耗时高于无关键词分页。
- CSV 自定义字段排序需要在服务端收集匹配记录，适合交互查询，但不替代专用数据库索引。若后续高频使用，应受控导入 MySQL 并为常用字段建立索引。
- BAAD 有 333 条完全重复行；只读浏览保持源数据，受控入库前需确认组合键和去重规则。
