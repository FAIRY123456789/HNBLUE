# HNBLUE 系统核心功能说明（FEATURES）

## 1. 碳储建模与 SHAP 解释
系统内置基于 CatBoost 的碳储量预测模型，利用全国森林异速生长数据集（BAAD）训练，支持全国与类红树林样本的碳储估算。通过 SHAP 分析提供特征贡献解释，帮助理解预测结果的生态学机制。

## 2. AI 碳助手问答
系统集成 AnythingLLM 桌面端与 DeepSeek API，结合私域知识库，支持生态学与建模相关问题的智能问答。用户可使用自然语言提问，得到专业化、结构化的解释与参考。

## 3. Redis Cluster 限流与互斥锁
后端基于 Redis Cluster 实现 API 限流，防止接口高频调用导致服务不可用。机制包括请求速率限制与热点资源的并发控制，提升系统稳健性。

## 4. 前端可视化地图与趋势展示
前端采用 Vue.js 与 ECharts，构建交互式地图与趋势分析视图。用户可在可视化界面浏览区域碳储与通量指标的空间分布、年度变化与指标对比，支持区域详情页与专题分析功能。
