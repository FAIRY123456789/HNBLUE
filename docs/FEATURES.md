# HNBLUE 系统核心功能说明（FEATURES）

## 1. 模型服务与解释边界
系统保留 CatBoost 推理、批量预测、敏感性分析和 SHAP 解释的服务接口。公开仓库不发布训练数据或训练后模型，默认使用明确标注的合成 fixture；私有部署通过 `HNBLUE_MODEL_PATH` 挂载可信制品。模型解释描述模型行为，不证明生态因果关系。

## 2. Agentic RAG 碳助手
系统自建混合检索与 Agent 编排：BM25、字符 TF-IDF、LSA、标题召回和加权 RRF 负责候选证据；Spring Boot 负责会话隔离、最小上下文、证据门控、提示注入检测、可选 DeepSeek 生成、引用校验和摘录式回退。公开仓库只包含合成知识包。

## 3. Redis 缓存与短期状态
后端使用单节点 Redis 管理热点查询缓存、登录窗口计数、临时封禁和密码重置状态。缓存键具有 HNBLUE 命名空间，查询按变化频率设置 TTL；Redis 不对公网开放。

## 4. 数据治理与可视化
Vue 3 与 ECharts 提供地图、趋势、数据表、来源卡片、模型输入和 Agent 流式输出。公开页面只读取合成指标 fixture 和小型合成 CSV；工作单状态机把重要数据变更显式纳入角色审核流程。
