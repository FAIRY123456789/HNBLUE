# 数据质量与许可证说明

## 质量等级规则

| 等级 | 判定规则 | 本轮来源 |
|---|---|---|
| A | 政府部门、国际组织、权威数据平台、同行评议论文中可直接核验的数据或正式数据集 | GMW/Zenodo、GEE、USGS、IPCC、Frontiers、MDPI、Blue Carbon Initiative、Verra |
| B | 政府报告、技术报告、项目方案、机构白皮书、论文摘要页中可核验的统计值 | 海南省政府报道、国家林草局规划页面、JORE 摘要页 |
| C | 方法参考、二级转载、新闻稿、科普文章 | GitHub/GEE 脚本案例、普通新闻稿 |
| D | 无法确认来源、时间、作者、许可证或原始出处的数据 | 本轮未纳入 seed |

## 许可证和使用限制

1. GMW 和 Zenodo 数据需按 DOI、版本和页面许可登记。大体量数据只记录下载 URL、版本、冷数据路径，不直接入仓库。
2. GEE、USGS、NASA 数据产品可作为开放遥感数据源使用，导出或二次分发时保留平台引用和产品引用。
3. MDPI 和 Frontiers 开放论文可记录题录、DOI、摘要级信息和表格字段线索。不得复制全文。
4. 政府网页可记录政策、项目、统计线索和 URL。若页面未明确开放数据许可，原文内容不得作为可再分发数据集。
5. GitHub 或 Notebook 只作为方法参考。未经原始数据核验的数值不得进入 `seed_*` 文件。
6. 模拟数据必须写入 `source_category=SIMULATED` 或 `is_simulated=1`。本轮未生成模拟数值记录。
